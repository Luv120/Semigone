PROBLEM STATEMENT

AI-Based Restoration of Degraded Images for Semiconductor Inspection

Why This Problem Matters

Semiconductor fabrication operates at nanometer scales where even a single undetected particle, scratch, or void can cause chip failure. Modern fabs inspect billions of die per year — image quality directly determines yield.

⚡ SPECKLE NOISE
  • Multiplicative noise from coherent laser illumination in optical wafer inspection (darkfield/brightfield).
  •  
  • I(x,y) = I_clean(x,y) · η(x,y)
  • where η ~ Gamma(L, 1/L)
  •  
  • Impact: Obscures sub-100nm particles and edge defects.
📊 GAUSSIAN + POISSON NOISE
  • Additive readout noise (detector thermal) + Poisson shot noise from low electron dose in SEM.
  •  
  • Low-dose SEM: dose ∈ [15, 80]
  • Readout: σ ∈ [0.01, 0.08]
  •  
  • Impact: Degrades CD-SEM metrology accuracy (LER/LWR).
🔍 LOW RESOLUTION
  • Pixel binning, low magnification, and diffraction-limited optics reduce spatial resolution.
  •  
  • Defocus PSF + 2x downsampling
  • + optical transfer function blur
  •  
  • Impact: Merges adjacent defects, loses critical dimension detail.

IDEA DESCRIPTION

Single-Backbone Restoration with Defect-Aware Intelligence

Core Insight: One fine-tuned backbone (NAFNet) handles ALL degradations jointly — noise, blur, and downsampling trained end-to-end together. A cheap XGBoost classifier provides a second interpretable signal specifically watching for the failure mode we care about most: defects being “cleaned away” during restoration.

WHY NAFNet?
  • ✓ No nonlinear activations → SimpleGate replaces ReLU/GELU
  • ✓ Pure ConvNet → 4-6x faster than SwinIR Transformer
  • ✓ UNet encoder-decoder with skip connections
  • ✓ <3ms inference, trains in ~15 min on 1 GPU
  • ✓ No GAN → zero hallucination risk for defect fidelity
  • ✓ Global residual: output = f(x) + x → identity baseline
  • ✓ Trivial ONNX/TensorRT export for production
ADDRESSING ALL 3 DEGRADATIONS

Joint End-to-End Training:

Degraded LR input → NAFNet → Clean HR output

  • 1. Speckle: Learned via Gamma noise in training pipeline, outperforms hand-tuned SRAD/Lee
  • 2. Gaussian + Poisson: Mixed noise model in synthetic degradation matches SEM physics
  • 3. Super-Resolution: PixelShuffle head for 2x upscaling after denoising in LR domain

MODEL ARCHITECTURE & LOSS DESIGN
NAFNet-Tiny Config:
  • width=16, enc=[1,1,1,2], mid=1, dec=[1,1,1,1]
  • img_channel=1 (grayscale), ~0.48M params
  • Blocks: LayerNorm → DWConv → SimpleGate → SCA
  • SR Head: Conv → PixelShuffle(2) → Conv
Composite Loss (No GAN):
  • L = L_Charb + 0.1·L_FFT + 0.05·L_SSIM
  •  + L_DefectAware(W · |pred-target|)
  • Charbonnier: sqrt((x-y)² + ε²), ε=1e-3
  • FFT: ||F(x) - F(y)||₁ → edge fidelity
  • W(x,y) = 1 + 15·P_defect(x,y)^1.5
Training Strategy:
  • Phase 0: Train XGBoost (~2 min)
  • Phase 1: Train NAFNet (~15 min)
  • Optimizer: AdamW, lr=1e-3
  • Scheduler: Cosine annealing
  • Patches: 128x128, batch=8

INNOVATION & UNIQUENESS

What Sets Our Approach Apart

1. DEFECT-AWARE SPATIAL LOSS WEIGHTING
  • Novel: XGBoost defect probabilities create a spatial weight map that forces the restoration network to be extra careful in defect regions during training.
  •  
  • W(x,y) = 1.0 + α · [P_defect(x,y)]β
  • Defect pixels get 15x higher loss weight than background
2. POST-HOC QC VERIFIER (NOT A 2ND MODEL)
  • Lightweight discrepancy check — not a second full model. Computes metrics ONLY over defect-flagged regions:
  •  
  • • Local SSIM on defect patches (threshold ≥ 0.82)
  • • Weber Contrast Preservation ρ ∈ [0.75, 1.30]
  • • Edge Preservation Index (EPI ≥ 0.70)
  • Flags images where defects were “cleaned away”
3. PHYSICS-BASED SYNTHETIC DEGRADATION
  • Not random noise — models real sensor physics:
  • • Poisson shot noise (electron dose statistics)
  • • Gaussian readout (detector thermal noise)
  • • Gamma speckle (coherent laser interference)
  • • Defocus PSF + stage drift blur + downsampling
  • Eliminates need for paired hardware-captured datasets
4. ZERO-HALLUCINATION FAST INFERENCE
  • • Non-GAN pixel-fidelity losses → no hallucinated defects
  • • SimpleGate replaces all activations → fewer FLOPs
  • • Single model, no cascaded errors
  • • <3ms GPU / <20ms CPU per 256x256 image
  • • Direct ONNX export, no custom operators
  • Production-ready for inline wafer inspection
